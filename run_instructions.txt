DIGIMON V-PET PROTOTYPE - Run Instructions

Tech Stack: Godot 4.3 (GDScript) - Cross-platform engine for pixel art games
- Game + Companion app share same data/save system
- Data-driven design via JSON files in data/
- All sprites are 64x64 pixel art placeholders (replace with real art)

How to Run:
1. Install Godot 4.3 from https://godotengine.org/download
2. Open Godot and import project from /workspace/app (select project.godot)
3. Run the project - main scene is res://scenes/main/Digivice.tscn

Scenes:
- Main Digivice: Feed, Train, Battle, Explore, Scan, Storage
- Companion App: View/storage box for transferring Digimon
- Training: Stat training minigame with fatigue
- Battle: Turn-based PVP battle system
- Explore: Node-based adventure with encounters
- Scan: Code/QR scan system for unlocking Digimon
- Digivice Upgrade: Upgrade tiers gating scan/capture
