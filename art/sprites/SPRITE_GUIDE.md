# Sprite Assets Guide

All sprites must be 64x64 or higher, clean high-end pixel art.

## Required sprites per Digimon:
- `*_idle.png` - Default standing animation
- `*_eat.png` - Eating animation
- `*_train.png` - Training animation
- `*_happy.png` - Happy animation
- `*_sad.png` - Sad/hungry animation

## Digimon included:
- botamon (Baby)
- agumon (Rookie)
- greymon (Champion)
- metalgreymon (Ultimate)
- wargreymon (Mega)

Replace placeholder files with actual pixel art meeting these specs.
